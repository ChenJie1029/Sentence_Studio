# 句听 · Sentence Studio

**把英文录音和原文整理成听写片段，一句一句，听懂英语。**

句听是一款面向英语听力学习的浏览器应用。导入录音和对应的英文原文，设置音频起止时间，即可按声音停顿和说话人变化生成练习片段，配合变速、循环、隐藏原文和听写核对完成学习。

原文支持文本、字幕、PDF 和图片。音频与文字在浏览器本机处理，学习记录保存在当前浏览器。

## 为什么做句听

听写时，反复拖动播放进度、寻找句子位置、对照原文，往往比练习本身更费时间。

句听把这些步骤集中到同一个工作台：先整理素材，再专注听、写、核对，让每一次重复都有明确的练习对象。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 音频范围设置 | 填写开始与结束秒数，支持小数，导入前可试听所选范围 |
| 多格式原文导入 | 支持 TXT、SRT、VTT、PDF，以及 PNG、JPG、JPEG、WEBP、BMP 图片 |
| PDF 与图片转文字 | 提取 PDF 文字层，对扫描页和图片进行英文文字识别，并提供逐页校对 |
| 按停顿切分 | 优先选择 8–15 秒内的自然停顿，辅助检测说话人切换 |
| 原文辅助匹配 | 保留确认后的原文，分界存疑时可试听并调整原文分配 |
| 变速播放 | 0.5–1.5 倍速，每档 0.1 |
| 单次与循环播放 | 可选只播放 1 遍，或循环 2、3、4、5 遍 |
| 隐藏原文 | 每次切换片段时默认隐藏，点击按钮后揭晓 |
| 听写与核对 | 输入听写、核对词语、记录完成状态，并自动保存进度 |
| 切点微调 | 试听并调整相邻片段的边界，重新匹配对应原文 |
| 素材导出 | 导出练习音频、逐段音频、字幕、原始材料及听写记录 |

## 快速开始

### 本地运行

准备 Node.js 运行环境，下载并解压仓库，进入包含 `server.mjs` 的项目目录，执行：

```sh
node server.mjs
```

然后在浏览器打开：

```text
http://127.0.0.1:4173/
```

Windows 用户也可以直接双击项目中的 **启动句听.cmd**。使用期间请保持启动窗口打开。

项目采用原生 HTML、CSS 和 JavaScript，无需安装前端依赖，也无需构建。请通过本地 HTTP 服务访问，直接双击 HTML 文件无法正常运行全部功能。

### 开始一份练习

1. 点击 **导入新素材**，选择录音文件。
2. 在弹出的窗口中填写开始与结束秒数，试听后确认范围。例如，1 分 30 秒填写 `90`。
3. 导入原文文件，或直接粘贴英文原文。
4. 对照原文件校对转换结果，确认页面顺序和最终原文。
5. 点击 **开始逐句切分**，分析所选录音中的停顿与说话人变化。
6. 如出现 **核对分段原文**，试听各段，调整相邻片段的原文分界后确认。
7. 选择播放速度和遍数，写下听到的内容，再显示原文核对。

## 切分规则

句听将录音整理为适合反复听写的练习片段，普通片段优先保持在 **8–15 秒**。

- 在时长合适时，优先选择自然停顿与说话人切换位置。
- 说话人不足 8 秒就发生切换时，等待后续合适的切点。
- 结尾剩余不足 8 秒时，完整保留剩余内容；较短的整段素材也会保留。
- 找不到可靠切点时，保留较长的连续语音，并显示提示，避免机械截断单词。
- 一个片段可以包含几句较短的英文句子，片段边界不一定与原文句号逐一对应。

语音识别只辅助匹配原文。个别词语误识别不会直接阻止音频切分，也不会自动替换正确原文。无法可靠确定文字分界时，需要试听确认。

## 播放与快捷键

选择 **1 遍**时，本句只播放一次，不循环；选择 2–5 遍时，按设置重复播放。重复间隔支持 0、1、2、3、5 秒，也可开启播完后自动进入下一句。

| 快捷键 | 操作 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 上一句 / 下一句 |
| `R` | 从头重听 |
| `T` | 显示 / 隐藏原文 |

输入听写、编辑文本或打开弹窗时，快捷键暂停生效，避免误操作。

## 支持的素材与限制

| 素材 | 支持范围 |
| --- | --- |
| 音频 | MP3、WAV、M4A 等浏览器可解码格式；单文件不超过 100 MB |
| 音频时长 | 本次选择的范围最长 20 分钟，原录音可以更长 |
| 文本与字幕 | UTF-8 编码的 TXT、SRT、VTT；每文件不超过 1 MB |
| PDF | 支持文字版、扫描版和混合页；每文件不超过 25 MB、30 页 |
| 图片 | PNG、JPG、JPEG、WEBP、BMP；每文件不超过 25 MB |
| 批量原文 | 最多 12 个文件、合计 60 页、总计不超过 80 MB |
| 最终原文 | 最多 60000 字符 |

多文件原文可调整顺序，并明确选择参与练习的页面。带时间轴的 SRT / VTT 需要单独导入，字幕原时间保留作参考，练习切点按所选音频重新确定。

## 数据与网络

音频分析、英文图片识别和原文匹配在浏览器内进行。素材、原文件、听写内容与学习进度保存在当前浏览器的本机存储中。

PDF、图片识别、说话人分析及语音模型首次使用需要联网加载。处理耗时取决于素材长度、网络和设备性能，因此目前不能保证首次使用时完全离线运行。

不同浏览器或网站地址之间的记录不会自动同步。清除浏览器数据会影响本机记录，重要学习内容可通过导出功能留存。

## 导出内容

可以分别导出完整练习音频、当前片段音频、全部片段打包文件和听写记录。全部片段 ZIP 包含：

```text
practice.wav        完整练习音频
practice.srt        与练习音频对应、从零开始的字幕
001.wav、002.wav…   每段独立音频
transcript.txt      分段英文原文
subtitles.srt       对应原录音时间的字幕
verification.json   音频范围、切分与原文校对记录
originals/          导入的原始文件（如有）
```

导出音频保留原始声音与速度，播放器中的变速设置仅用于练习。

## 示例素材

仓库中的 `examples/` 提供音频、文本、PDF 和图片示例。

**测试声音切换：**使用 `voice-change.wav` 和 `voice-change.txt`，选择完整音频范围。该示例约 24.34 秒，可用于观察两种声音之间的分段效果；素材来源及拼接说明见 `voice-change-source.txt`。

**测试音频范围和多格式导入：**使用 `manual-range.wav`，选择第 `5` 秒至第 `12.8` 秒。原文可选择 `original.txt`、任意一份 `original-*.pdf`，或按顺序导入 `page-1.png` 与 `page-2.png`。按当前时长规则，这段约 7.8 秒的内容整体保留为一个片段。

## 技术实现

| 部分 | 技术 |
| --- | --- |
| 页面与交互 | 原生 HTML、CSS、JavaScript ES Modules |
| 音频处理 | Web Audio API、OfflineAudioContext、Web Workers |
| 停顿切分 | 音频能量分析与时长约束 |
| 说话人变化 | Transformers.js 与 PyAnnote 音频帧分类模型 |
| 原文辅助匹配 | Whisper 英语模型，提供准确优先与轻量两种选择 |
| PDF 解析 | PDF.js |
| 图片转文字 | Tesseract.js 英文文字识别 |
| 本机存储 | IndexedDB、localStorage |
| 本地服务 | Node.js 内置 HTTP 服务 |

```text
.
├── dist/                       网页与浏览器端处理模块
```

### 运行检查

```sh
node --test tests/*.test.mjs
```

检查覆盖音频范围裁剪、停顿检测、说话人变化候选、8–15 秒时长规划、原文保留、存疑分界确认、字幕与音频导出等功能。

### 静态部署

`dist/` 可部署到支持 JavaScript 模块与 Web Workers 的 HTTPS 静态托管服务，无需额外的应用后端。部署环境需要允许页面加载所用的外部识别组件和模型资源。

## 当前限制

停顿与说话人分析可能受背景音乐、噪声、音色相近及重叠讲话影响；扫描页和图片的识别准确率也与清晰度、排版有关。请保留原文件校对与试听确认步骤。

当前文字识别和语音匹配主要面向英文材料。录音范围与原文应覆盖相同内容，范围内的额外讲解或缺失内容需要先整理后再练习。

## 问题反馈

反馈问题时，可说明浏览器、素材格式、选择的起止时间，以及实际结果与预期结果。若方便复现，可提供一段可公开使用的短录音及对应原文。
